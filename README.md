# NSA-KingDom

### **موتور تحلیل شبکه اجتماعی **

NSA Kingdom یک پروژه تحلیل شبکه اجتماعی (Social Network Analysis) مبتنی بر نظریه گراف است که تلاش می‌کند ارتباطات و رفتار های یک جامعه را آنالیز و برسی کند که با نتیجه آن ما میتوانیم الگوی های رفتاری افراد یک جامعه را شکل دهیم.

---

# ✨ قابلیت‌های پروژه

* مدل‌سازی شبکه اجتماعی به صورت گراف
* بارگذاری انواع دیتاست
* مدیریت کاربران و ارتباطات
* پیاده‌سازی الگوریتم BFS
* پیاده‌سازی الگوریتم DFS
* تشخیص گروه‌های دوستی (Connected Components)
* یافتن کوتاه‌ترین مسیر
* پیشنهاد دوست
* محاسبه آمار شبکه
* تشخیص پل‌های ارتباطی (Bridge)
* شناسایی افراد کلیدی (Articulation Points)

# 🧠 الگوریتم‌های استفاده‌شده

## BFS

کاربردها:

* یافتن کوتاه‌ترین مسیر
* محاسبه فاصله کاربران
* پیمایش شبکه

پیچیدگی زمانی:

O(V + E)

---

## DFS

کاربردها:

* پیمایش عمقی
* تشخیص گروه‌های دوستی
* تحلیل ساختار شبکه

پیچیدگی زمانی:

O(V + E)

---

## الگوریتم Tarjan

کاربردها:

* تشخیص پل‌های ارتباطی
* شناسایی افراد کلیدی
* تحلیل نقاط بحرانی شبکه

پیچیدگی زمانی:

O(V + E)

---

## سیستم پیشنهاد دوست

بر اساس نزدیکی کاربران در شبکه و تعداد دوستان مشترک، مناسب‌ترین افراد برای برقراری ارتباط پیشنهاد می‌شوند.

# 📊 آمار شبکه

پروژه قادر به محاسبه اطلاعات زیر است:

* تعداد کاربران
* تعداد ارتباط‌ها
* میانگین روابط هر کاربر
* بزرگ‌ترین جامعه
* پرارتباط‌ترین کاربر
* فاصله هر کاربر تا سایر کاربران
* اندازه جوامع مختلف
